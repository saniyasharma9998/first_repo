# Data Directory — Food Delivery Analytics

This directory contains all dataset files for the Food Delivery Analytics project.

## Structure

```
data/
├── raw/
│   └── food_delivery_orders.csv        # Raw synthetic dataset (~10,353 rows)
└── processed/
    └── cleaned_food_delivery_orders.csv # Cleaned + feature-engineered (~38 columns)
```

---

## Files

### `raw/food_delivery_orders.csv`

| Attribute | Value |
|---|---|
| Rows | ~10,353 (including ~31 intentional duplicates) |
| Columns | 23 |
| Period | January 1 – December 31, 2023 |
| Generated by | `src/data_generation.py` |

This is the **raw dataset** as it would arrive from a hypothetical data pipeline.
It includes:
- ~0.3% duplicate rows (intentional — for cleaning demonstration)
- ~2% missing `customer_rating` for delivered orders
- ~1% missing `delivery_partner_id`
- ~0.5% missing `distance_km`

### `processed/cleaned_food_delivery_orders.csv`

| Attribute | Value |
|---|---|
| Rows | ~10,322 (after duplicate removal) |
| Columns | 38 (23 original + 15 engineered) |
| Generated by | `src/data_cleaning.py` |

This is the **cleaned and feature-engineered dataset** used by:
- All Jupyter notebooks
- The Streamlit dashboard
- The test suite

---

## Regenerating the Data

```bash
# Step 1: Generate raw dataset
python src/data_generation.py

# Step 2: Run cleaning pipeline
python src/data_cleaning.py
```

Both scripts are idempotent — running them multiple times produces the same output
(seeded at `SEED = 42`).

## Revenue Definitions

| Metric | Formula |
|---|---|
| `gross_order_value` | `order_amount + delivery_fee` |
| `final_amount` | `gross_order_value − discount` |
| `net_revenue` | `final_amount` if `order_status = "Delivered"` else `0` |
